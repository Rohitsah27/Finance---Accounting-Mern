## ⚡ Key Features of the Docs Site
- **Instant Search (`Ctrl + K`)**: Live search across all submodules, accounting entries, and business concepts.
- **"Launch in App" Shortcuts**: Direct buttons on every page opening the live working prototype page.
- **Double-Entry Journal Tables**: Exact Debit / Credit postings for every workflow.
- **Responsive & Hierarchical Sidebar**: Matches the main app's sidebar series.
