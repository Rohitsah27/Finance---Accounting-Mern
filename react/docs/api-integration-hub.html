API Endpoints & Webhooks

Open API Hub

Core REST API Endpoints

  • POST /api/v1/policies/bind — Bind policy & generate AR invoice.
  • POST /api/v1/journals — Post manual/automated journal entry.
  • GET /api/v1/reports/trial-balance — Fetch live trial balance.
  • POST /api/v1/subledger/bordereau — Ingest monthly MGA BX.

Outbound Webhooks

  • policy.bound — Triggered on binding confirmation.
  • payment.reconciled — Fired when bank recon matches.
  • approval.required — Notifies external Slack/Teams channels.
