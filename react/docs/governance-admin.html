Governance, Administration & Security

Veridex enforces enterprise security, multi-tenant isolation, Role-Based Access Control (RBAC), immutable audit trail logging, integration APIs, and global configuration engines.

Immutable Logs Compliance

1. Immutable Audit Trail (`audit-trail.html`)

Open Audit Trail

What it does: Records every user action, login, journal post, policy binding, bank recon match, and approval event with cryptographic SHA-256 timestamping for SOC 1 / SOC 2 compliance.

RBAC Security

2. User Management & Role Access (`user-management.html`)

Open User Management

Role-Based Access Control (RBAC)

Assigns granular permissions (View, Create, Edit, Approve, Admin) across accounting, underwriting, and treasury modules.

Multi-Tenant Entity Segregation

Ensures brokers only see their policies and commissions, MGAs see their programs, and Carriers maintain full group oversight.

System Setup Admin

3. Configuration Centre & Onboarding

Open Config Centre

Includes the Configuration Centre (`admin-config-center.html`), Setup Wizard (`setup-wizard.html`), and Excel Onboarding Tool (`excel-onboarding.html`) for bulk importing Chart of Accounts, opening GL trial balances, and active policy portfolios.

REST API Webhooks

4. API & Webhook Integration Hub (`api-integration-hub.html`)

Open API Hub

Connects external Policy Administration Systems (PAS), Agency Management Systems (AMS like Applied Epic / AMS360), and banking core rails via secure JSON REST APIs and event-driven webhooks.
