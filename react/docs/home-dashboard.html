The Home Dashboard is the default landing page for executives, controllers, and accountants. It gives an immediate, high-level bird’s-eye view of cash balances, gross written premium, operational notifications, and quick action buttons.

Executive Hub Live Metrics

What the Home Dashboard Does

Open Live Dashboard

When you log into Veridex, this page aggregates financial data across all subsidiary entities:

1. KPI Metric Summary Cards

  • Gross Written Premium (GWP): Total premium bound in the active fiscal period.
  • Total Cash Balance: Combined Operating (`Account 1001`) and Premium Trust (`Account 1020`) funds.
  • Outstanding AR: Uncollected policyholder receivables.
  • Pending Approvals: Transactions awaiting your sign-off.

2. Quick Action Buttons

  • Bind New Policy: Fast-track quote-to-bind entry in PAS.
  • New Journal Entry: Create manual debit/credit posting.
  • Sync Bank Statements: Run automated bank recon match.
  • Switch Role Context: Toggle between Carrier, MGA, and Broker views.
