API & Integration Hub
Keys, webhooks, the full event catalogue and async import/export jobs, all in one place.
Two ways to keep data flowing in besides uploading a spreadsheet: generate an API key below and call the REST endpoints directly, or register a webhook (we give you a per-tenant signing secret) so an external system can push data to a URL of yours, or you can point your own sender at ours using that same secret. Pick one, both, or neither, spreadsheet upload always keeps working regardless.
REST convention: base path /api/v1/{resource}. An Idempotency-Key header is required on every financial POST. Errors are returned as RFC 9457 application/problem+json. List endpoints use cursor pagination (?cursor=), never page numbers.
